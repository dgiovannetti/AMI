# AMI v3.2.1

## Summary
- **Rilevamento linea più veloce**: timeout corti, short-circuit offline, ISP/VPN differiti dopo l’icona tray
- **Dashboard**: storico offline/unstable sul grafico (xlim + seed da CSV); fascia Link al posto del “barcode” a punti
- **macOS**: fix apertura Dashboard da menu (`triggered(bool)`); KeepAlive LaunchAgent più sicuro

## Install
Scarica lo ZIP della tua piattaforma (`AMI-v3.2.1-macos.zip` o `AMI-v3.2.1-windows.zip`), estrai e avvia **AMI.app** (macOS) o `AMI.exe` (Windows).

Su macOS: se non vedi l’icona, controlla il menu **«»** a destra nella menu bar.
