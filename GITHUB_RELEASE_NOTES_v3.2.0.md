# AMI v3.2.0

## Summary
- macOS: **solo icona tray** in menu bar (niente badge flottante sotto la barra che andava in sovrimpressione)
- macOS: avvio più stabile dopo lo splash (handler Dock differito, slot protetti, recovery tray)
- Build / deps: PyObjC obbligatorio su Darwin; packaging `.app` invariato

## Install
Scarica lo ZIP della tua piattaforma (`AMI-v3.2.0-macos.zip` o `AMI-v3.2.0-windows.zip`), estrai e avvia **AMI.app** (macOS) o `AMI.exe` (Windows).

Su macOS: se non vedi l’icona, controlla il menu **«»** a destra nella menu bar.
